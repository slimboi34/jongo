# Security policy

## Supported versions

Only the latest release of Jongo on PyPI gets security fixes. Upgrade with
`pip install -U jongo`.

## Reporting a vulnerability

Please report it privately. Do not open a public issue.

Use GitHub's private vulnerability reporting:
<https://github.com/slimboi34/jongo/security/advisories/new>
(the **Security** tab, then **Report a vulnerability**).

Include the Jongo version, a minimal reproduction, and what an attacker gains.
You should get a reply within a week. Once a fix is released, the advisory is
published and you are credited unless you ask not to be.
